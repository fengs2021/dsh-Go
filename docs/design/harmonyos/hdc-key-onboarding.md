# 网络调试密钥（HDC）怎么来、怎么让别人的手机也认

手机工具（`mcp__phone__shell` / `mcp__phone__ui` / `mcp__phone__app`）走的是 App 进程内自建的 HDC 客户端：
`runtime/ohos/phone/hdc-link.mjs` 直连本机 hdcd（开发者选项里的无线调试端口），用 RSA 公钥完成
SessionHandShake 鉴权后以 shell uid 执行命令。**能不能用，取决于设备是否认识这把密钥**，不取决于 App
有没有内置密钥。

## 1. 密钥从哪里来（优先级）

`resolveKeyPath()`（`hdc-link.mjs`）按顺序取第一项命中的：

| 顺序 | 来源 | 路径 | 什么时候用 |
| --- | --- | --- | --- |
| 1 | 显式选项 | `options.keyPath` | 测试注入 |
| 2 | 环境变量 | `DSH_GO_PHONE_KEY` | 排障时指定 |
| 3 | **用户自备** | `$DSH_HOME/hdc-client/id_rsa`（`userKeyPath()`） | 用户想把手机上已知的密钥带进来 |
| 4 | 随包内置 | `<runtime>/phone/hdc-key/id_rsa`（`shippedKeyPath`） | 打包者本人调试用 |
| 5 | 自动生成 | 写到 `userKeyPath()` | 上面都不存在时，首次连接现生成 3072 位 RSA |

v37 之前顺序是「内置优先」，导致**用户自备密钥永远不生效**；现在改成自备优先，内置只作兜底。

## 2. 「内置密钥」对别人意味着什么

内置密钥只对打包者本人的手机有效：那台手机的 known_hosts 里已经有它的公钥。别人装同一个 HAP：

- App 仍然会拿内置密钥去握手；
- 手机上会弹「是否允许调试」，选**始终允许**之后，这台手机才认识它；
- 选了取消 / 只允许一次，下次还要再弹，未授权期间所有手机工具报鉴权超时。

所以「让别人也能用」不需要发文件，需要**一次授权动作**；如果要完全静默，就用用户自己手机上已经信任的密钥。

## 3. 公钥必须恰好 625 字节

设备端 `AlreadyInKnownHosts` 用公钥 PEM 字符串长度做匹配，长度不是 **625**（含末尾换行）时「始终允许」不会持久化，
表现为每次连接都弹窗。3072 位 RSA 的 SPKI PEM 刚好 625 字节，这也是默认生成参数用 3072 的原因。
`diagnoseHdc()` 会检查这个长度并在不为 625 时给出提示。

## 4. 用户侧三步（App 之外）

1. 设置 › 系统 › 开发者选项 › **无线调试** 打开并保持开启（关掉就没有监听端口，`discoverPorts()` 找不到）。
2. 第一次用手机工具时，手机弹「是否允许调试」→ 选**始终允许**。
3. 没看到弹窗：开发者选项 › **撤销 USB 调试授权** → 回到 DSH 重试。

带自己密钥的用户：把桌面 `hdc` 用的 `id_rsa` 放到手机 App 数据目录的 `hdc-client/id_rsa`
（即 `$DSH_HOME/hdc-client/id_rsa`，权限 0600）。桌面 hdc 已经在这台手机的 known_hosts 里，放进去后**不再弹窗**。

## 5. 自检：`mcp__phone__hdc`

`diagnoseHdc()` 一次返回：无线调试发现到的端口、当前密钥来源与 SHA-256 指纹、PEM 字节数、鉴权是否成功与耗时，
以及按现状生成的中文修复步骤。工具 `mcp__phone__hdc`（只读）把它包给模型，用来回答「为什么手机操作用不了」
和「换人用时要做什么」。引擎启动时的探针（`index.mjs`）也会在失败时把同一套步骤写进 `engine.log`。

## 6. 错误文案（引导式）

| 场景 | 现在的文案要点 |
| --- | --- |
| 没有监听端口 | 指出「设置 › 系统 › 开发者选项 › 无线调试 并保持开启」 |
| 鉴权超时 | 指出弹窗要选「始终允许」，以及「撤销 USB 调试授权」重试 |
| 鉴权完成前连接关闭 | 同上（多半是点了取消或只允许一次） |

## 7. 已知限制

- 弹窗只能由用户在系统界面点，App 不能代点（那是系统弹窗，不是普通界面）。
- 撤销授权后内置密钥也要重新授权，没有「静默恢复」的办法。
- known_hosts 在设备侧，shell uid 写不了；只能通过用户授权或使用已受信任的密钥。
- 用户手册（`docs/guide/harmony/zh/04-phone-control.md`）当前对外仍写着「不看屏幕、不点按其他应用」，
  与 ohos/v8 已实现的 `mcp__phone__ui` 不一致，属于需要产品口径确认的遗留项，本版没有改手册正文。
